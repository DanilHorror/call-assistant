# Оценка качества

## Ручной прогон сценариев оператора

`data/eval_operator_scenarios.json` — 10 фраз с ожидаемым поведением: ответы по базе знаний, продолжение темы, отсутствие выдуманных цифр, фильтр поддакиваний, веб-поиск, роль оператора. Фразы озвучиваются в звонок по порядку (например, через «Прослушать» в Google Переводчике с выходом на VB-Cable), результат сверяется с полем `expect`.

Первый прогон (02.10.2026): 6 из 10 без замечаний. Найдено и исправлено: выдуманная скидка «10–15%» (карточка не проходила порог поиска + не было запрета на цифры вне базы), потерянная подсказка при обрыве соединения GigaChat (не было повторов), ответ от лица ИИ на просьбу перезвонить, лишний запрос к модели на «Ага, понятно».

## Наборы для batch-скриптов

Скрипты `src/batch_test_*.py` прогоняют подсказки и судью на наборах сценариев и пишут результаты в CSV. В репозиторий включён `data/judge_test_cases.json` (15 каверзных случаев для судьи-классификатора); остальные наборы собраны на реальных разговорах и не публикуются.

```
python src/batch_test_judge.py
```

## Юнит-тесты

```
pip install -r requirements-dev.txt
pytest
```

Покрывают фильтр поддакиваний, классификацию ошибок и повторы GigaChat (без сети), поиск по базе знаний и порог продолжения темы.
